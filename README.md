# Savage Zyrex V2 (MongoDB Edition)

### Setup Checklist:
1. **GitHub**: Upload these files to your repo.
2. **Environment Variables**: Copy `.env.example` to a new file named `.env` and fill in the values:
   - **Telegram**: Get `TELEGRAM_TOKEN` from @BotFather.
   - **Groq**: Get `GROQ_API_KEY` from console.groq.com.
3. **Run**: Execute `python main.py` to start the bot.
